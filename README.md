# Breast Cancer Classification using Machine Learning

## Overview
This project explores binary classification of breast tumours as benign or malignant using the Breast Cancer Wisconsin Diagnostic dataset.

## Dataset
The dataset contains 569 samples and 30 numerical features describing characteristics of cell nuclei.

## Algorithms Implemented
- Logistic Regression
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Gaussian Naive Bayes
- Gradient Boosting
- Extra Trees Classifier

## Technologies Used
- Python
- NumPy and Pandas
- Scikit-learn
- Matplotlib and Seaborn

## Workflow
1. Data loading and exploration
2. Data preprocessing
3. Train-test splitting
4. Model training
5. Performance evaluation
6. Confusion matrix analysis
7. Model comparison

## Evaluation Metrics
Accuracy, Precision, Sensitivity, Specificity, F1-score and ROC-AUC.

## How to Run
Open the notebook using Google Colab or Jupyter Notebook. Ensure the CSV dataset is available in the notebook's working directory.

## Disclaimer
This is an educational machine learning project, not a clinically validated diagnostic tool.
